# iM 시니어 금융여권 (Silver Credit Passport)

> 계리 기반 **대안신용평가** + **DID 신용증명**으로 대구 고령층의 포용금융을 실현하는 AI·블록체인 서비스
> 2026 AI Blockchain Challenge in Daegu (주최: iM뱅크 · 대구디지털혁신진흥원)

---

## 한 줄 요약

고령층은 **소득은 반토막인데 자산은 유지되고 실제 연체율도 낮은** 저위험 고객이다. 그런데 소득 중심의 전통 신용평가는 이들을 고위험으로 분류해 배제한다. 우리는 **자산·연금 신호를 반영한 대안신용평가**로 이 저위험 시니어를 식별하고, 결과를 **DID 신용여권**으로 발급해 서민금융 접근을 돕는다.

## 핵심 근거 (가계금융복지조사 2025, 60세 이상 9,643가구)

| 연령대 | 처분가능소득 | 순자산 | 부채/자산 | 실제 연체율 |
|---|---|---|---|---|
| 60-64 | 6,800만 | 63,927만 | 13.7% | 6.2% |
| 65-69 | 5,569만 | 54,565만 | 11.6% | 7.6% |
| 70-74 | 4,417만 | 61,346만 | 8.9% | 6.6% |
| 75+ | 2,762만 | 38,415만 | 6.7% | 6.0% |

→ 소득은 급감하지만 **연체율은 40·50대(7.0·7.8%)와 비슷하거나 낮다.** "저소득 = 고위험"이 시니어에서 깨진다.

## 모델 결과 (60세 이상 부채보유 가구 2,934건 · 실제 연체 라벨)

| 모델 | 피처 | AUC |
|---|---|---|
| 베이스라인 | 연령 + 근로소득 (전통 소득기준) | **0.525** (사실상 무작위) |
| **대안 모델** | + 공적연금 + 금융자산 + 순자산 + 자가 + DSR | **0.651** |

- LightGBM 피처 중요도: **공적연금 > 금융자산 > 순자산** — 시니어 신용을 가르는 건 근로소득이 아니라 연금·자산.
- **계리 레이어:** KOSIS 완전생명표의 나이·성별 생존확률로 가중한 연금현가로 감당가능 대출을 산출.
- **공정성:** 의료비·건강지출은 위험신호로 사용하지 않음. 성별·장애가구 간 성능 격차 점검.

```
   (계리)          (연계·시연)        (핵심 엔진)         (블록체인)
```

## 실행 방법 (Google Colab)

1. 이 저장소의 노트북 · `gfc_loader.py` · `kosis_life_table_2024.csv`를 Colab에 업로드
2. **데이터 파일은 직접 받아야 함** (아래 데이터 안내 참고) → Colab에 업로드
3. 노트북 CONFIG에서 `USE_SYNTHETIC = False`, `DATA_PATH`를 데이터 파일명으로 지정
4. 런타임 → 모두 실행

> 데이터 없이도 `USE_SYNTHETIC = True`로 두면 합성 데이터로 전체 파이프라인이 그대로 실행됩니다.

## 기술 스택

- **AI/데이터:** Python, pandas, scikit-learn(로지스틱 스코어카드), LightGBM
- **계리:** KOSIS 완전생명표 기반 생존확률 가중 연금현가
- **블록체인:** DID / 검증가능자격증명(VC) — 옴니원 오픈DID 기반 (발급·검증·지갑)
- **확장:** 대구 자체 메인넷 '대구체인' · 분산신원 '다대구' 연동 로드맵
